Nombre del Emprendimiento: Almacen-El-Mercadito-AED2
Integrantes: Miño Antonio, Gabriel Moyano, Luciano Olavarria
Problema que resuelve: Nuestro proyecto busca solucionar el problema que tiene un almacén cuando controla sus productos manualmente.
Tema elegido: clase 6: Colecciones y Listas: Elegimos la Clase 6 porque las listas (List) nos permiten manejar el stock del almacén sin límites de tamaño fijo. y usamos una colección de listas (List<List<Articulo>>) para agrupar los artículos por categoría.
Tecnologias: Java, Eclipse, Trello, Kanban.
